How it works

Encode

A custom audio autoencoder maps each clip to a latent representation. TIPSTER decomposes it into structure, timbre, and a residual component.

Recombine

Using ConDe, the model learns additive components. At transfer time, it takes structure from the source and timbre from the reference.

Decode

The autoencoder reconstructs the edited clip in a single decoding pass. Training pairs come from ASAP MIDI performances rendered as piano, harp, xylophone, and vibraphone.
